# Планирование: анализ, идентификация проблем и поиск решений

## Анализ проблемных мест системы

| № | Категория                 | Проблема                                                                                                                                      | Последствия                                           |
|---|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------|
| 1 | **Производительность**    | Долгий расчет стоимости в MES (до 30 минут)                                                                                                   | Блокировка обработки заказов, рост времени выполнения |
| 2 | **Надежность**            | Потеря заказов при интеграции через API                                                                                                       | Прямые финансовые потери, потеря контрактов           |
| 3 | **Производительность UI** | Медленная загрузка дашборда MES                                                                                                               | Снижение эффективности операторов, влияние на KPI     |
| 4 | **Масштабируемость**      | Линейный рост нагрузки без горизонтального масштабирования                                                                                    | Деградация производительности при росте заказов       |
| 5 | **Наблюдаемость**         | Отсутствие единой системы мониторинга, логов и трейсинга. Невозможно определить корневые причины проблем с производительностью и надежностью. | Невозможность идентифицировать источники проблем      |
| 6 | **Интеграция**            | Ненадежная коммуникация через RabbitMQ                                                                                                        | Потеря сообщений, рассинхронизация статусов           |
| 7 | **Безопасность**          | API без механизмов throttling                                                                                                                 | Риски DDoS, неконтролируемая нагрузка                 |
| 8 | **Тестирование**          | Ручное E2E-тестирование блокирует релизы                                                                                                      | Замедление выпуска обновлений                         |
| 9 | **Процессы**              | Ручное деплой                                                                                                                                 | Задержки выпуска версий                               |

## Инициативы по улучшению

### Приоритет 1: Критические

1. **Оптимизация производительности MES**
    - Кэширование данных дашборда
    - Оптимизация запросов к базе данных
    - Выделение тяжелых расчетов в отдельные очереди

2. **Внедрение системы наблюдаемости**
    - Добавление и настройка логирования
    - Внедрение трассировки
    - Дашборд отслеживания статусов и времени обработки
    - Алёрты на просроченные заказы
    - Метрики времени выполнения на каждом этапе

### Приоритет 2: Высокие

3. **Автоматизация тестирования**
    - E2E-тесты критичных сценариев
    - Интеграционные тесты API
    - Автоматизация pre-production тестирования

### Приоритет 3: Средний

4. **Архитектурная трансформация**
    - Выделение сервиса расчетов стоимости
    - Event-Driven архитектура для заказов

5. **Масштабирование инфраструктуры**
    - Горизонтальное масштабирование MES API

## Целевая архитектура через 6 месяцев

- **Микросервисная архитектура** с выделенным сервисом расчетов
- **Горизонтально масштабируемые сервисы**
- **Централизованная система мониторинга** включает: логирование, сбор метрик и трассировку
- **Гарантированная доставка событий** через Outbox Pattern
- **Распределенное кэширование** для повышения производительности
- **Автоматизация CI/CD**

## Три ключевые инициативы на ближайшие полгода

1. **Оптимизация производительности MES** - решает проблему медленной работы операторов и блокирующих расчетов

2. **Внедрение системы наблюдаемости** - дает видимость проблем, возможность анализировать их и позволит определить
   узкие места. Позволит отслеживать влияние изменений на производительность платформы

3. **Масштабирование инфраструктуры** - подготовить систему к росту нагрузки
